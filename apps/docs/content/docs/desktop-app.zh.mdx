本文适用于定制版本。使用当前定制源码或部署维护者提供的产物；上游应用安装包不包含这些修改。

## 构建或取得定制安装包

使用经过审查的定制提交构建的安装包，或维护者提供的定制包。准备自己的安装包时使用下面的工作区脚本，并满足 Go、目标平台构建和签名要求。文档列出命令不代表本次已经执行构建。

```bash
pnpm install --frozen-lockfile
pnpm --filter @multica/desktop package
```

## 必须配置服务地址

`apiUrl` 和 `appUrl` 都是必填项。Web 地址用于浏览器登录和分享链接，不会根据 API 域名猜测。将有效 JSON 保存到 `~/.multica/desktop.json`，Windows 路径为 `%USERPROFILE%\.multica\desktop.json`。Windows 使用 UTF-8，避免保存成 `desktop.json.txt`。修改后重启应用。

```json
{
  "schemaVersion": 1,
  "apiUrl": "http://localhost:8080",
  "appUrl": "http://localhost:3000"
}
```

Compose 示例只绑定主机的 `127.0.0.1`。跨机器访问时使用带 TLS 的反向代理，并配置自己的 `FRONTEND_ORIGIN`、`MULTICA_APP_URL`、`MULTICA_PUBLIC_URL`、`CORS_ALLOWED_ORIGINS` 和上传地址。桌面端的 `localhost` 指桌面端所在电脑；Docker 在其他机器时需要替换示例地址。正确转发认证、健康检查和 WebSocket，并从执行电脑验证。

## 标签页和本机执行器

桌面端复用共享页面，按工作区保存标签页。登录后，它会在当前 API 专属的 profile 中启动内置定制 CLI，不会选择系统 CLI 或下载上游替代版本。智能体工具、登录状态和模型额度仍需自行准备，可在设置中查看守护进程状态和日志。

## 使用自己的更新来源

只有 `updateUrl` 指向自己的通用 Electron 更新源时才启用更新。可选的 `links.docsUrl`、`links.changelogUrl`、`links.downloadUrl`、`links.communityUrl`、`links.feedbackUrl` 设置帮助入口，未配置就不展示。`links.cliInstallUrl` 和 `links.cliInstallWindowsUrl` 可提供自己的 CLI 安装脚本，`links.runtimeReleaseUrl` 设置独立运行时的发布元数据。桌面端托管的运行时不会查询 CLI 发布源。内置 CLI 缺失时应重装或重新构建定制桌面包。

## 语音输入

Desktop 可以在本机把语音转成文字，填入聊天、评论、回复和新建任务的描述。语音输入**默认关闭**，网页版不提供此功能。

1. 打开**设置 → 语音输入**，开启**语音输入**。
2. 下载支持所用语言的语音模型。下载需要联网，安装后在本机转写。如果页面提示本机无法使用转写，说明当前构建没有可用的语音引擎。
3. 按提示允许麦克风访问。也可以在同一设置页选择并测试麦克风。

默认的**点按或按住**模式支持两种用法：点击麦克风开始，点击勾号插入文字；或按住麦克风说话，松开后插入。插入的文字留在编辑器中，供你检查。聊天和评论的录音栏中，点击发送按钮或在录音时按 `Enter` 会转写并发送；`Esc` 取消。

语音快捷键**默认未设置**。在**设置 → 快捷键**中绑定后，只要支持的编辑器可见，即使未聚焦也能使用。**语音输入**页还可以把触发方式改为仅点按或仅按住。

### 录音与历史记录

音频在本机转写，不会为转写而上传。发送的文字按普通聊天消息或评论提交。

录音和转写文字**默认在本机保留 30 天**。在**设置 → 语音输入 → 历史记录**中，可以播放录音、复制文字、重新转写、删除单条或全部清除。**保留历史记录**可选不保留、1 天、7 天、30 天或永久。

关闭**语音输入**会隐藏麦克风并停用语音快捷键，不会删除已有录音；仍可在同一页面管理历史记录。
