この文書はカスタム版向けです。現在のソース、または運用担当者が提供した成果物を使用してください。上流のアプリ配布物にはこの変更は含まれません。

## カスタムパッケージの用意

レビュー済みソースまたは管理者のカスタムパッケージを使います。自分で作成する場合は以下のスクリプトと Go、対象 OS の構築・署名環境が必要です。ここにあるコマンドはビルド実施を意味しません。

```bash
pnpm install --frozen-lockfile
pnpm --filter @multica/desktop package
```

## 接続先の必須設定

初回起動時に統合サービスの URL を入力すると、Desktop はその URL を API と Web の両方の接続先として保存します。API と Web アプリを別々の URL に配置する場合は、以下のファイルを設定します。

`apiUrl` と `appUrl` は両方必須です。Web URL はブラウザログインと共有用で、API ホストから推測しません。UTF-8 JSON を `~/.multica/desktop.json`、Windows では `%USERPROFILE%\.multica\desktop.json` に保存します。`.txt` 拡張子を付けず、変更後に再起動してください。

```json
{
  "schemaVersion": 1,
  "apiUrl": "http://localhost:8080",
  "appUrl": "http://localhost:3000"
}
```

Compose のホストポートは `127.0.0.1` にバインドされます。リモート接続では TLS リバースプロキシと、自分の `FRONTEND_ORIGIN`、`MULTICA_APP_URL`、`MULTICA_PUBLIC_URL`、`CORS_ALLOWED_ORIGINS`、アップロード URL を設定します。Desktop の `localhost` は Desktop の端末です。認証、ヘルスチェック、WebSocket の経路を設定し、実行端末から確認してください。

## タブとローカル実行

共有ページを再利用し、タブをワークスペース別に保持します。ログイン後は設定済み API 専用 profile で同梱 CLI を起動します。システム CLI の選択や上流バイナリの取得は行いません。エージェントツールの認証とモデル利用枠は別途必要です。設定で状態とログを確認できます。

タブ内でボード、リスト、テーブル、スイムレーン、ガントを切り替えると、ビューごとに前回のスクロール位置に戻ります。ボードでは横方向の位置と各列内の位置も保持されます。

サインアウトすると、このマシンに保存されたすべてのタブが消去されるため、次にサインインした人が前のアカウントの残したページを見ることはありません。

## 自分の更新元

`updateUrl` に自分の汎用 Electron フィードを設定した場合のみ更新を有効化します。ヘルプは `links.docsUrl`、`links.changelogUrl`、`links.downloadUrl`、`links.communityUrl`、`links.feedbackUrl` で指定し、未設定のリンクは表示しません。自分の CLI 配布用に `links.cliInstallUrl`、`links.cliInstallWindowsUrl`、`links.runtimeReleaseUrl` を設定できます。Desktop 管理の CLI はリリース照会を行いません。同梱 CLI がなければカスタム Desktop を再構築・再インストールしてください。

手動確認やダウンロードに失敗した場合、設定画面に短いメッセージと**再試行**ボタンが表示されます。現在のバージョンを使い続けながら再試行できます。

## 音声入力

Desktop では、このコンピューター上で音声を文字に変換し、チャット、コメント、返信、タスク作成時の説明に入力できます。音声入力は**デフォルトでオフ**です。Web アプリでは利用できません。

1. **設定 → 音声入力**で**音声入力**をオンにします。
2. 使用する言語に対応した音声モデルをダウンロードします。ダウンロードにはインターネット接続が必要ですが、インストール後の文字起こしはローカルで行います。オンデバイスの文字起こしを利用できないと表示される場合、このビルドにはコンピューターで使える音声エンジンがありません。
3. 確認が表示されたらマイクへのアクセスを許可します。同じ設定ページでマイクの選択とテストもできます。

デフォルトの**タップまたは長押し**では、マイクをクリックして開始し、チェックマークをクリックしてテキストを挿入できます。または、マイクを長押しして話し、離すと挿入されます。挿入されたテキストは編集欄に残り、確認できます。チャットやコメントでは、録音バーの送信ボタン、またはそのバーで録音中の `Enter` で文字起こしして送信します。`Esc` でキャンセルします。

音声入力のショートカットは**デフォルトでは未設定**です。**設定 → ショートカット**で割り当てると、対応する入力欄が表示されていれば、フォーカスがなくても使えます。**音声入力**ページでは、起動方法をタップのみ、長押しのみに変更できます。

### 録音と履歴

音声はこのコンピューター上で文字起こしされ、文字起こしのためにアップロードされません。送信したテキストは通常のチャットメッセージやコメントとして送られます。

録音と文字起こしは**デフォルトで 30 日間**ローカルに保存されます。**設定 → 音声入力 → 履歴**で、録音の再生、テキストのコピー、再度の文字起こし、個別削除、一括消去ができます。**履歴の保存期間**は、保存しない、1 日、7 日、30 日、無期限から選べます。

**音声入力**をオフにすると、マイクが非表示になり、音声入力のショートカットも無効になります。保存済みの録音は削除されず、同じページで履歴を管理できます。
