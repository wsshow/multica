この文書はカスタム版向けです。現在のソース、または運用担当者が提供した成果物を使用してください。上流のアプリ配布物にはこの変更は含まれません。

## カスタムパッケージの用意

レビュー済みソースまたは管理者のカスタムパッケージを使います。自分で作成する場合は以下のスクリプトと Go、対象 OS の構築・署名環境が必要です。ここにあるコマンドはビルド実施を意味しません。

```bash
pnpm install --frozen-lockfile
pnpm --filter @multica/desktop package
```

## 接続先の必須設定

`apiUrl` と `appUrl` は両方必須です。Web URL はブラウザログインと共有用で、API ホストから推測しません。UTF-8 JSON を `~/.multica/desktop.json`、Windows では `%USERPROFILE%\.multica\desktop.json` に保存します。`.txt` 拡張子を付けず、変更後に再起動してください。

```json
{
  "schemaVersion": 1,
  "apiUrl": "http://localhost:8080",
  "appUrl": "http://localhost:3000"
}
```

Compose のホストポートは `127.0.0.1` にバインドされます。リモート接続では TLS リバースプロキシと、自分の `FRONTEND_ORIGIN`、`MULTICA_APP_URL`、`MULTICA_PUBLIC_URL`、`CORS_ALLOWED_ORIGINS`、アップロード URL を設定します。Desktop の `localhost` は Desktop の端末です。認証、ヘルスチェック、WebSocket の経路を設定し、実行端末から確認してください。

## タブとローカル実行

共有ページを再利用し、タブをワークスペース別に保持します。ログイン後は設定済み API 専用 profile で同梱 CLI を起動します。システム CLI の選択や上流バイナリの取得は行いません。エージェントツールの認証とモデル利用枠は別途必要です。設定で状態とログを確認できます。

## 自分の更新元

`updateUrl` に自分の汎用 Electron フィードを設定した場合のみ更新を有効化します。ヘルプは `links.docsUrl`、`links.changelogUrl`、`links.downloadUrl`、`links.communityUrl`、`links.feedbackUrl` で指定し、未設定のリンクは表示しません。自分の CLI 配布用に `links.cliInstallUrl`、`links.cliInstallWindowsUrl`、`links.runtimeReleaseUrl` を設定できます。Desktop 管理の CLI はリリース照会を行いません。同梱 CLI がなければカスタム Desktop を再構築・再インストールしてください。
