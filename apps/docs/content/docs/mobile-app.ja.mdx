最初のデバイスまたは Release ビルド前に `apps/mobile/.env.production.example` を無視対象の `apps/mobile/.env.production.local` にコピーし、`EXPO_PUBLIC_API_URL` と `EXPO_PUBLIC_WEB_URL` の両方を自分の配備先に設定します。Mobile の環境設定は Desktop と独立しています。継承した公開サービスの値のままビルドせず、カスタム checkout または管理者のソースを使用してください。

Multica の iOS クライアントはまだ App Store にありません。Mac で公開されているソースリポジトリから Release 版をビルドし、自分の iPhone にインストールできます。Android クライアントはまだ提供されていません。

カスタム App はビルド前に指定した API と Web に接続します。アカウントとデータはその配備先に属し、公開サービスを自動選択しません。

## 事前準備

必要なもの:

- Xcode をインストールした Mac。
- **Xcode → Settings → Accounts** でサインイン済みの Apple ID。
- USB で接続した iPhone。
- iPhone の **設定 → プライバシーとセキュリティ** でデベロッパモードを有効にしておくこと。
- Node.js、pnpm、Git。

Xcode や実機の開発環境がまだ設定されていない場合は、先に Expo の [iOS デバイスの環境セットアップ](https://docs.expo.dev/get-started/set-up-your-environment/)を完了してください。

## iPhone へのインストール

<Steps>
<Step>
リポジトリをクローンして依存関係をインストールします:

```bash
# Run from the customized repository root.
pnpm install
```
</Step>
<Step>
リポジトリのルートから実行します:

```bash
pnpm ios:mobile:device:prod:release
```

これは Metro に依存しない Release 版をビルドし、接続中の iPhone にインストールします。初回ビルドは iOS の依存関係をダウンロードして React Native をコンパイルするため時間がかかりますが、以降は Xcode のキャッシュを再利用します。
</Step>
<Step>
iPhone でアプリを開きます。起動がブロックされた場合は、**設定 → 一般 → VPN とデバイス管理** で対応する開発者証明書を信頼してください。
</Step>
</Steps>

## 無料署名の 7 日制限

無料の Apple ID で署名したアプリは 7 日間しか使えません。期限が切れたら、iPhone を Mac に接続し直し、同じビルドコマンドをもう一度実行すれば再署名できます。

Apple Developer Program アカウントで署名すると有効期間が長くなり、TestFlight や正式な配布にも使えます。どちらの署名でも、再インストールや再署名によってサーバー側のデータが失われることはありません。

## 署名の失敗

Xcode が `No matching provisioning profiles found` と報告する場合、デフォルトの bundle identifier があなたの Apple ID に属していない可能性があります。自分が管理する逆ドメイン名に切り替えて再ビルドしてください:

```bash
export EXPO_BUNDLE_IDENTIFIER_PROD=com.yourname.multica
pnpm ios:mobile:device:prod:release
```

この値はあなたの Apple Developer team で利用できれば十分で、Multica のアカウントやワークスペースには影響しません。

## 更新

自分でインストールした iOS ビルドは自動更新されません。最新のコードを取得し、依存関係を更新して再ビルドします:

```bash
pnpm install
pnpm ios:mobile:device:prod:release
```

## セルフホストインスタンスへの接続

`apps/mobile/.env.production.example` を基に、無視対象の `apps/mobile/.env.production.local` へ自分の 2 つの URL を設定します。Desktop 設定とは独立しています。iPhone から到達可能なホストを使い、端末の `localhost` をサーバーとしないでください。再構築・更新前にレビュー済みカスタムコミットを選択します。署名、実機、開発モードは現在の `apps/mobile/README.md` を参照してください。

```dotenv
EXPO_PUBLIC_API_URL=https://api.example.com
EXPO_PUBLIC_WEB_URL=https://app.example.com
```

```bash
pnpm ios:mobile:device:prod:release
```
