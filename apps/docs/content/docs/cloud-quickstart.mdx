title: Customized quickstart
description: Connect to your own deployment and complete the first agent task.
---

This documentation describes the customized edition. Use this checkout or artifacts supplied by your deployment maintainer; upstream application packages do not contain these changes.

1. Deploy your server using [customized self-hosting](/self-host-quickstart), then open its own web URL.

2. Configure [Electron Desktop](/desktop-app), or build and connect the [CLI](/cli) with explicit API and web addresses.

3. Install and sign in to a supported [agent tool](/install-agent-runtime) on the execution computer.

4. Create an agent, select that computer/runtime and model, then assign a small issue to it.

5. Follow the execution log, read the result comment, and verify the produced files.

```bash
multica setup self-host --server-url http://localhost:8080 --app-url http://localhost:3000
multica auth status
multica daemon status
```

Verify `/readyz`, login, runtime registration, task completion, and attachments. `/health` is liveness only. Product telemetry, crash reporting, anonymous reporting, and operational metrics are disabled; `/metrics` and `/health/realtime` are unavailable. User-facing usage, costs, history, and runtime liveness remain functional.
