---
title: カスタム版クイックスタート
description: 自分のサービスに接続して最初のタスクを実行します。
---

この文書はカスタム版向けです。現在のソース、または運用担当者が提供した成果物を使用してください。上流のアプリ配布物にはこの変更は含まれません。

1. [セルフホスト](/self-host-quickstart)で自分のサービスを配備し、その Web URL を開きます。

2. [Desktop](/desktop-app) を設定するか、[CLI](/cli) を構築して API と Web URL を明示します。

3. 実行端末で対応[エージェントツール](/install-agent-runtime)をインストールしてログインします。

4. エージェントとランタイム、モデルを選び、小さなタスクを割り当てます。

5. 実行ログ、結果コメント、生成ファイルを確認します。

```bash
multica setup self-host --server-url http://localhost:8080 --app-url http://localhost:3000
multica auth status
multica daemon status
```

`/readyz`、ログイン、ランタイム登録、タスク結果、添付を確認します。`/health` は生存確認のみです。テレメトリ、クラッシュ送信、匿名送信、運用メトリクスは無効です。`/metrics` と `/health/realtime` は使えません。画面の使用量、コスト、履歴、オンライン状態は維持されます。
