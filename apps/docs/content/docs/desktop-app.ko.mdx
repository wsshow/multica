이 문서는 맞춤 버전용입니다. 현재 소스 또는 배포 관리자가 제공한 산출물을 사용하세요. 원본 프로젝트의 앱 배포물에는 이 변경 사항이 없습니다.

## 맞춤 패키지 준비

검토된 소스로 만든 패키지나 관리자가 제공한 맞춤 패키지를 사용합니다. 직접 만들 때는 다음 스크립트와 Go, 대상 플랫폼의 빌드 및 서명 환경이 필요합니다. 문서의 명령은 실제 빌드가 수행되었다는 뜻이 아닙니다.

```bash
pnpm install --frozen-lockfile
pnpm --filter @multica/desktop package
```

## 필수 서비스 설정

처음 실행할 때 통합 서비스 URL을 입력하면 Desktop이 이 주소를 API와 Web 주소로 저장합니다. API와 Web 앱을 서로 다른 주소에 배포했다면 아래 파일을 설정하세요.

`apiUrl`과 `appUrl`은 모두 필수입니다. Web URL은 브라우저 로그인과 공유에 사용되며 API 호스트에서 추측하지 않습니다. UTF-8 JSON을 `~/.multica/desktop.json`, Windows에서는 `%USERPROFILE%\.multica\desktop.json`에 저장하세요. `.txt` 확장자를 붙이지 말고 수정 후 앱을 재시작합니다.

```json
{
  "schemaVersion": 1,
  "apiUrl": "http://localhost:8080",
  "appUrl": "http://localhost:3000"
}
```

Compose의 호스트 포트는 `127.0.0.1`에 바인딩됩니다. 원격 접속은 TLS 리버스 프록시와 자체 `FRONTEND_ORIGIN`, `MULTICA_APP_URL`, `MULTICA_PUBLIC_URL`, `CORS_ALLOWED_ORIGINS`, 업로드 URL을 설정하세요. Desktop의 `localhost`는 Desktop 컴퓨터를 의미합니다. 인증, 상태 확인, WebSocket 경로를 설정하고 실행 컴퓨터에서 검증합니다.

## 탭과 로컬 실행

공유 페이지를 재사용하며 작업 공간별 탭을 유지합니다. 로그인하면 설정된 API 전용 profile에서 포함된 맞춤 CLI를 시작합니다. 시스템 CLI를 선택하거나 원본 바이너리를 내려받지 않습니다. 에이전트 도구 인증과 모델 사용량은 따로 준비합니다. 설정에서 상태와 로그를 볼 수 있습니다.

탭 안에서 보드, 리스트, 테이블, 스윔레인, 간트 사이를 전환하면 각 뷰의 마지막 스크롤 위치로 돌아갑니다. 보드에서는 가로 스크롤 위치와 각 열 안의 스크롤 위치도 유지됩니다.

로그아웃하면 로컬에 저장된 모든 탭이 삭제되어 다음 로그인 사용자가 이전 계정의 페이지를 보지 못합니다.

## 직접 관리하는 업데이트 출처

`updateUrl`에 자체 일반 Electron 피드를 설정해야 업데이트가 활성화됩니다. 도움말은 `links.docsUrl`, `links.changelogUrl`, `links.downloadUrl`, `links.communityUrl`, `links.feedbackUrl`로 지정하고 누락된 링크는 숨깁니다. 자체 CLI 배포는 `links.cliInstallUrl`, `links.cliInstallWindowsUrl`, `links.runtimeReleaseUrl`을 설정합니다. Desktop 관리 runtime은 CLI 릴리스를 조회하지 않습니다. 포함된 CLI가 없으면 맞춤 Desktop 패키지를 다시 설치하거나 빌드하세요.

수동 확인이나 다운로드에 실패하면 설정에 짧은 안내와 **다시 시도** 버튼이 표시됩니다. 다시 시도하는 동안 현재 버전을 계속 사용할 수 있습니다.

## 음성 입력

Desktop은 이 컴퓨터에서 음성을 텍스트로 변환해 채팅, 댓글, 답글, 태스크 생성 시 설명에 입력할 수 있습니다. 음성 입력은 **기본적으로 꺼져 있으며**, 웹 앱에서는 사용할 수 없습니다.

1. **설정 → 음성 입력**에서 **음성 입력**을 켭니다.
2. 사용하는 언어를 지원하는 음성 모델을 다운로드합니다. 다운로드에는 인터넷 연결이 필요하지만, 설치 후 변환은 로컬에서 처리됩니다. 기기 내 받아쓰기를 사용할 수 없다고 표시되면 현재 빌드에 이 컴퓨터에서 사용할 수 있는 음성 엔진이 없는 것입니다.
3. 요청이 나타나면 마이크 접근을 허용합니다. 같은 설정 페이지에서 마이크를 선택하고 테스트할 수도 있습니다.

기본 **탭 또는 길게 누르기** 모드에서는 마이크를 클릭해 시작하고 확인 표시를 클릭해 텍스트를 삽입하거나, 마이크를 누른 채 말하고 손을 떼어 삽입할 수 있습니다. 삽입한 텍스트는 편집기에 남아 확인할 수 있습니다. 채팅과 댓글에서는 녹음 막대의 보내기 버튼을 누르거나 그 막대에서 녹음 중 `Enter`를 누르면 변환 후 전송합니다. `Esc`는 취소합니다.

음성 입력 단축키는 **기본적으로 지정되어 있지 않습니다**. **설정 → 단축키**에서 지정하면 지원하는 편집기가 화면에 보이는 동안 포커스 없이도 사용할 수 있습니다. **음성 입력** 페이지에서 실행 방식을 탭만 또는 길게 누르기만으로 바꿀 수도 있습니다.

### 녹음과 기록

음성은 이 컴퓨터에서 변환되며, 변환을 위해 업로드되지 않습니다. 전송한 텍스트는 일반 채팅 메시지나 댓글로 제출됩니다.

녹음과 텍스트는 **기본적으로 30일간** 로컬에 보관됩니다. **설정 → 음성 입력 → 기록**에서 녹음 재생, 텍스트 복사, 다시 변환, 개별 삭제, 모두 지우기를 할 수 있습니다. **기록 보관**은 보관 안 함, 1일, 7일, 30일, 계속 중에서 선택합니다.

**음성 입력**을 끄면 마이크가 숨겨지고 음성 단축키도 비활성화됩니다. 기존 녹음은 삭제되지 않으며 같은 페이지에서 기록을 관리할 수 있습니다.
