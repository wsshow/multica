---
title: 定制版本快速开始
description: 连接自建服务，完成第一个智能体任务。
---

本文适用于定制版本。使用当前定制源码或部署维护者提供的产物；上游应用安装包不包含这些修改。

1. 按[定制版本自托管](/self-host-quickstart)部署服务，打开自己的 Web 地址。

2. 配置 [Electron 桌面端](/desktop-app)，或构建 [CLI](/cli)并显式设置 API 和 Web 地址。

3. 在执行电脑安装并登录受支持的[智能体工具](/install-agent-runtime)。

4. 创建智能体，选择执行电脑、运行时和模型，再分配一个小任务。

5. 查看执行日志和结果评论，核对生成的文件。

```bash
multica setup self-host --server-url http://localhost:8080 --app-url http://localhost:3000
multica auth status
multica daemon status
```

验证 `/readyz`、登录、运行时注册、任务执行和附件。`/health` 只说明进程存活。产品遥测、崩溃上报、匿名上报和运维指标已禁用，`/metrics`、`/health/realtime` 不可用；界面使用的用量、成本、执行历史和运行时在线状态仍然保留。
